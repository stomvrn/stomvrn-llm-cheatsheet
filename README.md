# Шпаргалка · Нейросети

> Какую нейросеть выбрать. 24 плитки. Работает офлайн.

**[Открыть →](https://stomvrn.github.io/llm-cheatsheet/)**

## Что это

Одностраничный справочник о нейросетях. Пять разделов, 24 раскрывающихся плитки. Понятия (LLM, параметры, контекст, галлюцинации), выбор модели (для русского, для медицины, бесплатно, офлайн), правила запроса, приёмы проверки честности, тесты для сравнения.

Прогресс чтения сохраняется. Готовые формулировки копируются одной кнопкой. Всё работает без интернета.

## Принципы

- **Single-file** — один HTML, всё внутри
- **Offline-first** — работает без интернета
- **Zero dependencies** — ни CDN, ни библиотек, ни аналитики
- **Strict CSP** — `connect-src 'none'`
- **Local-only** — прогресс остаётся в браузере
